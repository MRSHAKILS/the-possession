## Figma Make prompt

Design a single-page web app called The Possession, a clinical case file for a possessed AI model.

- Sections, in order: masthead, controls, observation, explanation, results table, footer.
- Masthead: small label "Case file / Qwen 2.5 7B / 28 layers", a very large serif title, one short paragraph.
- Controls: six question buttons, a five-stop strength slider showing its value, and a "Perform exorcism" button.
- Observation: on the left, the model's answer in large serif type. On the right, a heatmap with 28 rows of layers and one column per token, with labeled bands for "possessed 16-21" and "exorcised 22-25".
- Two themes: clean is bone paper #efe9dc with ink #1b1714. Possessed is near-black #0b0605 with text #f0c9b8, and possessed words in ember red #d8341f.
- Type: Newsreader for text, IBM Plex Mono for labels and data.
- No gradients, glows, rounded cards, candles, skulls or marigolds. It should read as a hospital record that is slowly going wrong.
- Include a 375px mobile layout.
